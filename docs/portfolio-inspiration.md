## Addition: Project Index

The resulting addition is a searchable project browser with a desktop poster preview, subtle entrance/selection animation, keyboard shortcuts, and direct navigation to existing case studies. Its colors, typography, numbering, pixel motif, images, and descriptions follow this portfolio's established paper-and-ink design and approved content.

This adapts interaction ideas, with original component and CSS implementation. No reference site's code, branding, project descriptions, screenshots, or private data were copied into the portfolio.

All existing sections, 17 projects, homepage search/category filters, light/dark themes, portrait, contribution calendar, toolkit, contact form, and case-study pages remain available. The dialog uses native focus containment, restores scroll/focus on dismissal, and reduces animation when requested by the visitor's operating system.
